# Shaghayegh Salarian — QA Portfolio

Minimal dark QA-dashboard style portfolio built with plain HTML, CSS and JavaScript.

## GitHub Pages

1. Create a GitHub repository (for example `shaghayegh-qa-portfolio`).
2. Upload all files in this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select your main branch and `/ (root)`, then save.
5. Your portfolio will be published by GitHub Pages.

No build step or framework is required.

## Files

- `index.html` — page structure/content
- `style.css` — responsive dark dashboard styling
- `script.js` — mobile navigation + dynamic year
- `profile.jpg` — supplied profile photo
- `ShaghayeghSalarianQaResume.pdf` — CV download
